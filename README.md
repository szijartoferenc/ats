# 🤖 Intelligent ATS - AI Resume and Job Description Analyzer

This Streamlit application allows users to upload their resume and compare it to a job description using an AI-powered Applicant Tracking System (ATS) built with the Cohere API. The app provides keyword analysis, suitability scoring, and personalized improvement suggestions.

## 🚀 Features

- Upload resume in PDF, DOCX, or TXT format
- Paste job description for comparison
- AI-generated feedback and matching score (0–100)
- Keyword density analysis and visualization
- Highlighted suggestions for missing skills
- Downloadable keyword statistics (CSV, Excel)
- Session history for score comparison

## 🧠 Powered by

- [Cohere API](https://cohere.com/)
- [Streamlit](https://streamlit.io/)
- [Plotly](https://plotly.com/python/)
- [python-docx](https://pypi.org/project/python-docx/)
- [PyMuPDF](https://pymupdf.readthedocs.io/)


# 🤖 Intelligent ATS – AI Önéletrajz és Álláshirdetés Elemző

Ez a Streamlit-alapú alkalmazás lehetővé teszi az önéletrajz feltöltését és mesterséges intelligenciával történő összehasonlítását egy álláshirdetéssel. Az eszköz a Cohere API segítségével elemzi a kulcsszavakat, értékeli az egyezést, és hasznos javaslatokat ad a pályázat javításához.

## 🚀 Főbb funkciók

- Önéletrajz feltöltése PDF, DOCX vagy TXT formátumban
- Álláshirdetés beillesztése elemzéshez
- AI által generált visszajelzés és egyezési pontszám (0–100)
- Kulcsszó-gyakoriság elemzése és vizualizációja
- Hiányzó készségek kiemelése (technikai és soft skillek)
- Kulcsszavas statisztika letölthető (CSV, Excel)
- Pontszámok összehasonlítása munkák között
